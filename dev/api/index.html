API reference

DiscreteDynamicSurvivalAnalysis.DiscreteDynamicSurvivalAnalysis — Module
DiscreteDynamicSurvivalAnalysis

Discrete Dynamic Survival Analysis (DDSA): Bayesian inference for epidemic models from case line lists. A deterministic discrete-time SIR map on the calendar grid of the data gives the expected attack fraction τ and infection-time distribution f; individual infection and removal times are then treated as survival data, with log-likelihood

ℓ = ℓ_constr (final size, K ~ Binomial(N, τ))
  + ℓ_I      (infection times, Multinomial(K, f))
  + ℓ_R      (recovery intervals, discrete phase-type infectious period)

plus right-censoring and removal-only terms where the data need them. Integer-valued parameters (the number of infectious stages r, an unknown population size N) are summed out exactly, so the continuous parameters are sampled with NUTS (Turing.jl).

Main entry points: linelist/LineList (data), DDSAModel (model), fit_ddsa (inference), posterior_summary and posterior_predictive (results). Building blocks for custom models: forward_map, ddsa_loglikelihood and the term functions, and the submodules PhaseTypeDistributions and IntegerParameters, whose exports are re-exported.

Workflow

Data

DiscreteDynamicSurvivalAnalysis.LineList — Type
LineList

Binned case line list of one population (or one group of a multi-group model), on a grid of nsteps steps of length Δt. Step k covers the time interval [(k-1)Δt, kΔt) measured from the start of observation (with Δt = 1 day, step 1 is day 0).

Fields

  • nsteps::Int: number of steps of the forward map (the observation window).
  • Δt::Float64: step length, in the time unit of the data (e.g. days).
  • infection_counts::Vector{Int}: number of cases whose infection (onset) time falls in each step (length nsteps): the data of the infection-time term ℓ_I.
  • final_size::Int: the number of cases K in the final-size term ℓ_constr, including cases whose infection time is unknown.
  • recovery_intervals::Vector{Int}: observed infection-to-removal intervals, in steps (≥ 1): the data of the recovery term ℓ_R. These may include initial infectives.
  • censored::Vector{Bool}: true where the interval is right-censored (the case was still infectious after recovery_intervals[i] steps, at the end of observation).
  • removal_only_steps::Vector{Int}: removal step of each case whose infection time is unknown; their likelihood sums over the possible infection steps (convolution term).

Construct it directly from binned data with the keyword constructor below, or from raw event times with linelist.

DiscreteDynamicSurvivalAnalysis.linelist — Function
linelist(infection_times, removal_times; origin = nothing, Δt = 1.0, nsteps = nothing,
         censor_at = nothing) -> LineList

Bin a case line list given as event times into a LineList. Times are real numbers in the time unit of Δt, measured from the start of observation (time 0 is the start of step 1), or calendar dates with origin; missing marks an unknown time. Each entry is one case.

  • Infection step: floor(t / Δt) + 1 (calendar binning: with Δt = 1 day, the cases of day d are in step d + 1).
  • Grid length: nsteps if given, otherwise the step of the last infection time. An infection time beyond the grid is an error (filter the data to the observation window first).
  • Recovery interval (both times known): max(1, round(Int, (t_rem - t_inf) / Δt)) steps, i.e. rounded to the nearest step, with same-step removals counted as one step. If censor_at is given and t_rem ≥ censor_at, the interval is right-censored at max(1, round(Int, (censor_at - t_inf) / Δt)).
  • Infection time missing, removal known: the case enters removal_only_steps at step floor(t_rem / Δt) + 1, clamped to 1:nsteps.
  • Removal time missing: the case contributes its infection time only (no recovery term). To treat it as still infectious at the end of observation instead, give a removal time ≥ censor_at.
  • Final size: the number of cases.
  • Dates: with origin (a Date or DateTime, the start of step 1), the times must be Dates or DateTimes (or missing). They are converted to days since origin, so Δt is in days (Δt = 7 bins by week). censor_at may then be a date or a number of days since origin; nsteps is still a number of steps.

Throws DimensionMismatch if the two vectors differ in length, and ArgumentError for negative or non-finite times, a removal before infection, a case with both times missing, an infection time beyond the grid or at/after censor_at, an empty line list, dates without origin (or numbers with it), or a date before origin.

Examples

onset   = [0.2, 1.5, 2.1, missing, 4.8]
removal = [4.0, missing, 7.9, 6.3, 9.5]
data = linelist(onset, removal; nsteps = 8, censor_at = 8.0)

using Dates
day0 = Date(2024, 3, 4)
onset   = [day0, day0 + Day(2), missing]
removal = [day0 + Day(5), day0 + Day(9), day0 + Day(6)]
data = linelist(onset, removal; origin = day0, nsteps = 7, censor_at = day0 + Day(7))

Model specification

DiscreteDynamicSurvivalAnalysis.DDSAModel — Type
DDSAModel(; infectious_period, priors, population = nothing, terms = :all,
          transmission = :β, guards = NumericalGuards())

Specification of a single-population DDSA model, fitted with fit_ddsa or turned into a Turing model with turing_model.

Keywords

  • infectious_period::InfectiousPeriodModel: GeometricIP, NegBinGLCT or NegBinBoxcar.
  • priors::NamedTuple: one univariate Distributions prior per sampled parameter:
    • transmission: β (rate per unit time) or, with transmission = :R0, R0 (then β = R0 / mean_ip, which requires the :mean_ip IP parameter);
    • ρ: initially infected fraction (needed whenever the forward map is used);
    • the IP parameter named by infectious_period.parameter: p, γ or mean_ip.
  • population: number at risk in the final-size term: a known integer N, a range N_min:N_max (unknown N with a discrete uniform prior, summed out exactly), or an NGrid (unknown N with any prior). Required when :final_size is in terms.
  • terms: :all or a tuple of likelihood terms from (:final_size, :infection_times, :recovery, :removal_only) (terms without data contribute zero). Parameters that no term needs are not sampled: e.g. terms = (:recovery,) samples only the IP parameter.
  • transmission: :β or :R0.
  • guards: NumericalGuards applied to the map output.

Throws ArgumentError for missing or unused priors, priors that are not univariate distributions, inconsistent parameterisations, or a missing population.

Example

spec = DDSAModel(infectious_period = NegBinGLCT(1:10),
                 priors = (β = Uniform(1e-4, 2.5), ρ = Beta(1, 98), p = Beta(1, 1)),
                 population = 99)

DiscreteDynamicSurvivalAnalysis.InfectiousPeriodModel — Type
InfectiousPeriodModel

Infectious-period (IP) model of a DDSAModel: which distribution the recovery intervals follow and how infected individuals progress in the forward map. Subtypes: GeometricIP, NegBinGLCT, NegBinBoxcar.

Each has a parameter field naming the sampled IP parameter:

  • :p: per-step progression (removal, for one stage) probability p ∈ (0, 1);
  • :γ: removal rate per unit time, p = 1 − exp(−γ Δt) (geometric only);
  • :mean_ip: mean infectious period μ in time units, p = r Δt / μ.
source
DiscreteDynamicSurvivalAnalysis.GeometricIP — Type
GeometricIP(; parameter = :p)

Geometric infectious period (one stage, r ≡ 1): removal with probability p per step, so P(W = n) = p (1 − p)^(n−1) and the mean is 1/p steps. The map is the classical discrete-time SIR map. parameter is :p, :γ (rate per unit time) or :mean_ip.

source
DiscreteDynamicSurvivalAnalysis.NegBinGLCT — Type
NegBinGLCT(r_support; parameter = :p)

Negative binomial infectious period with r ∈ r_support geometric stages (support {r, r+1, …}, mean r/p steps), propagated through the GLCT forward map. The number of stages is summed out of the likelihood with a discrete uniform prior on r_support (one forward-map run per value), and drawn afterwards from its exact conditional posterior. Values of r above the shortest observed (uncensored) recovery interval have zero likelihood. parameter is :p or :mean_ip.

source
DiscreteDynamicSurvivalAnalysis.NegBinBoxcar — Type
NegBinBoxcar(r_support, K_age; parameter = :p, truncation = :absorb)

The negative binomial infectious period of NegBinGLCT propagated through a Boxcar (infection-age) map with K_age age classes, whose removal probabilities are the discrete hazard of the distribution truncated at K_age (discrete_hazard; truncation = :absorb or :condition). The recovery term uses the untruncated distribution.

source
DiscreteDynamicSurvivalAnalysis.NumericalGuards — Type
NumericalGuards(; τ_bounds = (0.0, 1.0), f_floor = 0.0)

Numerical guards applied to the forward-map output before the likelihood is evaluated.

  • τ_bounds = (lo, hi): the attack fraction is clamped to [lo, hi] before it enters the final-size term. The default (0, 1) leaves the exact likelihood unchanged (the final-size term is -Inf at a boundary that is incompatible with the data).
  • f_floor: if positive, the infection-time distribution is floored at this value and renormalised before the infection-time and removal-only terms.

The guards only matter when the map produces attack fractions or infection probabilities at those extremes.

source
DiscreteDynamicSurvivalAnalysis.turing_model — Function
turing_model(spec::DDSAModel, data::LineList) -> DynamicPPL.Model

Turing model of spec for data. Its parameters are those named in spec.priors; the number of stages (if any) is summed out of the likelihood and an unknown population size is summed out of the final-size term. The model returns (lps, τ): the per-r log-likelihoods and guarded attack fractions, from which fit_ddsa draws r and N after sampling. Use it directly to sample with other Turing settings, or to evaluate logjoint/loglikelihood at given parameters.

Inference

DiscreteDynamicSurvivalAnalysis.fit_ddsa — Function
fit_ddsa([rng], spec::DDSAModel, data::LineList; ndraws = 2000, nchains = 4,
         sampler = default_sampler(), parallel = MCMCThreads(), initial_params = :data,
         progress = false, verbose = false) -> DDSAFit

Sample the posterior of spec given data with Turing, then draw the summed-out integer parameters (r, N) once per MCMC draw from their exact conditional posteriors. The defaults are the manuscript's settings: 4 chains of 2,000 draws after 1,000 NUTS adaptation steps.

  • rng: random number generator for the initial values, the sampler and the integer draws (default Random.default_rng()); a seeded generator gives reproducible results.
  • parallel: MCMCThreads() (chains on Julia threads; start Julia with --threads), MCMCSerial() or MCMCDistributed().
  • initial_params: :data (jittered data-based starting values, data_based_inits), :prior (draws from the prior), or a vector of one Turing initialisation per chain (e.g. InitFromParams((β = 0.2, p = 0.5, ρ = 0.01))).
  • progress: show Turing's progress bars.
  • verbose: show Turing's informational messages (e.g. "Found initial step size"); warnings are always shown.

Throws ArgumentError for invalid settings and for data incompatible with spec (e.g. a known population smaller than the final size).

source
DiscreteDynamicSurvivalAnalysis.DDSAFit — Type
DDSAFit

Result of fit_ddsa.

Fields

  • spec::DDSAModel: the model specification.
  • data::LineList: the data.
  • model: the Turing model (turing_model).
  • chain::MCMCChains.Chains: posterior draws of the sampled parameters, with the summed-out integer parameters added as columns: :r (number of stages, when r has more than one value) and :N (population size, when it is unknown).

  • τ::Matrix{Float64}: the (guarded) attack fraction of each draw, for its drawn r (iterations × chains; NaN when the model has no forward map).

DiscreteDynamicSurvivalAnalysis.data_based_inits — Function
data_based_inits(rng, spec::DDSAModel, data::LineList, n) -> Vector

Jittered data-based starting values for n chains (the heuristic of the manuscript):

  • mean infectious period μ₀: the mean observed recovery interval (if the recovery term is used), otherwise the prior median;
  • p₀ = min δ / mean δ (negative binomial) or 1 / mean δ (geometric), γ₀ = −log(1 − p₀)/Δt;
  • R₀ from the final-size relation R̂₀ = −log(1 − z)/z, z = K/N, for a known population, or R̂₀ = 1 for an unknown one; β₀ = R̂₀ / μ₀;
  • ρ₀: the prior median.

Each value is multiplied by exp(0.1 z), z ~ Normal(0, 1) (drawn from rng), and clamped to the 1%–99% quantiles of its prior. Returns InitFromParams objects for sample.

Results

DiscreteDynamicSurvivalAnalysis.posterior_draws — Function
posterior_draws(fit::DDSAFit) -> NamedTuple

Posterior draws pooled over chains (chain 1 first, then chain 2, …), as vectors:

  • the sampled parameters (β or R0, p/γ/mean_ip, ρ, as in the model);
  • r: number of stages (1 for a geometric infectious period);
  • N: population size (constant when known), and K_over_N = K/N when it is unknown;
  • τ: attack fraction of the map (after the numerical guards);
  • derived: β (if R0 was sampled), p (per-step progression probability), mean_ip (mean infectious period r Δt / p, time units), mean_ip_steps (r / p) and R0 = β · mean_ip (for a geometric period, β / p per step).

Fields that a model does not have (e.g. β in a recovery-only model) are omitted.

DiscreteDynamicSurvivalAnalysis.posterior_predictive — Function
posterior_predictive([rng], fit::DDSAFit; ndraws = 500, scale = :expected_known) -> PosteriorPredictive

Posterior predictive infection curve: for ndraws posterior draws evenly spaced over the pooled chains, the forward map is re-run at the draw's parameters (including its r) and the expected cases per step are computed as below. N is the draw's population size, K the final size and K_known = Σ counts the number of cases with a known infection time.

  • scale = :expected_known (default): (K_known / K) N τ f, the expected number of cases with a known infection time, which is what the observed counts count. It assumes that infection times are missing independently of when the infection happened. When every infection time is known it equals :expected;
  • scale = :expected: N τ f, the expected new infections of all cases. With missing infection times it lies above the observed counts by the factor K / K_known;
  • scale = :observed_total: K_known f, the infection-time distribution scaled to the observed counts. It checks the shape of the curve only.

Also draws one final size Binomial(N, τ) per draw from rng, to compare with K. Needs a model with a forward map.

DiscreteDynamicSurvivalAnalysis.InfectionStructure — Type
InfectionStructure

How infected individuals progress to removal in the forward map. Subtypes: GLCT (phase-type stages) and Boxcar (infection-age classes with a discrete hazard).

DiscreteDynamicSurvivalAnalysis.GLCT — Type
GLCT(dph::DPH)

Generalised linear chain trick structure: the infected population is a vector x over the transient states of the discrete phase-type distribution dph (initial distribution α, transition matrix S). Each step, x ← S' x + α λ, where λ is the number of new infections. A geometric infectious period is the one-state case (dph_geometric(p)), which gives the classical discrete-time SIR map.

source
DiscreteDynamicSurvivalAnalysis.Boxcar — Type
Boxcar(hazard::AbstractVector)
Boxcar(dph::DPH, K_age::Integer; truncation = :absorb)

Infection-age (Boxcar) structure with K_age = length(hazard) age classes: each step, a fraction hazard[k] of the infected of age k is removed and the rest move to age k + 1; new infections enter age 1. The second form builds the hazard from a dwell-time distribution with discrete_hazard, whose truncation keyword selects how the distribution is truncated at K_age classes (:absorb or :condition).

DiscreteDynamicSurvivalAnalysis.forward_map — Function
forward_map(structure, β, ρ, nsteps; Δt = 1.0) -> MapSolution
forward_map(structure, foi, ρ::AbstractVector, nsteps; Δt = 1.0) -> MapSolution

Run the deterministic discrete-time SIR map of DDSA for nsteps steps of length Δt.

One group. β ≥ 0 is the transmission rate per unit time and ρ ∈ [0, 1) the initially infected fraction: S₀ = 1 − ρ, and the initial infectives enter the first state (GLCT) or age class (Boxcar). Each step, the new infections are λ = (1 − exp(−β I Δt)) S with I the infected fraction, so S decreases monotonically.

G groups. ρ holds the initially infected fraction of each group (fractions of each group's own size) and foi gives the force of infection on every group from the vector I of infected fractions:

  • a G × G matrix B: rates = B * I (B[g, h] is the transmission rate from group h to g);
  • any callable foi(I) returning G rates (e.g. a closure over parameters), which must accept vectors of ForwardDiff Duals when used for inference.

Each group then evolves as in the one-group map with its own rate.

Returns a MapSolution with the susceptible fractions, the attack fraction(s) τ = S₀ − S_T and the normalised infection-time distribution(s) f, both computed from the new infections recorded at each step. The element type follows the parameters, so the map is ForwardDiff-compatible.

Example

sol = forward_map(GLCT(dph_negative_binomial(4, 0.6)), 0.5, 0.01, 40)
attack_fraction(sol), infection_pmf(sol)
# two groups with a transmission matrix
sol2 = forward_map(GLCT(dph_geometric(0.2)), [0.4 0.1; 0.1 0.3], [0.01, 0.0], 60)

DiscreteDynamicSurvivalAnalysis.forward_map! — Function
forward_map!(S_hist, structure, β, ρ; Δt = 1.0) -> S_hist
forward_map!(S_hist, structure, foi, ρ::AbstractVector; Δt = 1.0) -> S_hist

Run the forward map and write the susceptible fractions at steps 0, …, nsteps into S_hist (a vector of length nsteps + 1 for one group; an (nsteps + 1) × G matrix for G groups). Only S_hist is mutated. See forward_map for the arguments; the element type of S_hist must hold the promoted parameter types (e.g. ForwardDiff Duals). forward_map also records the new infections per step, from which it builds τ and f.

source
DiscreteDynamicSurvivalAnalysis.MapSolution — Type
MapSolution

Output of forward_map.

Fields

  • S: susceptible fractions at steps 0, 1, …, nsteps: a vector (one group) or an (nsteps + 1) × G matrix (G groups).
  • τ: attack fraction(s) over the window: the new infections summed over the steps, which equals S₀ − S_T (scalar, or vector over groups).
  • f: infection-time distribution(s): new infections per step normalised to sum to one (vector, or nsteps × G matrix). If a group has no infections, its f is uniform.

τ and f are computed from the new infections recorded at each step, not from differences of S, so they keep full relative precision when the infections are tiny (e.g. R0 < 1).

  • Δt: step length.

Accessors: attack_fraction, infection_pmf, susceptible_fraction.

Likelihood

DiscreteDynamicSurvivalAnalysis.ddsa_loglikelihood — Function
ddsa_loglikelihood(sol::MapSolution, data::LineList, d; population, group = 1,
                   guards = NumericalGuards(), terms = DDSA_TERMS) -> (loglik, τ)

DDSA log-likelihood of the line list data given a forward-map solution sol (group group of a multi-group solution) and the infectious-period distribution d, summing the requested terms:

  • :final_size: final_size_loglik(population, data.final_size, τ) (needs population: a known N or an NGrid);
  • :infection_times: infection_time_loglik(data.infection_counts, f);
  • :recovery: recovery_loglik(d, data.recovery_intervals, data.censored);
  • :removal_only: removal_only_loglik(d, f, data.removal_only_steps).

τ and f are taken from sol after the NumericalGuards. Returns the log-likelihood (-Inf if the guarded infection-time distribution is invalid) and the guarded attack fraction τ, which is what is needed to draw N afterwards with sample_N.

For a model with several groups, call it once per group with the terms that belong to that group and add the shared terms (e.g. a recovery term pooled across groups) once.

source
DiscreteDynamicSurvivalAnalysis.final_size_loglik — Function
final_size_loglik(population, K, τ)

Final-size term ℓ_constr: log P(K | N, τ) for K ~ Binomial(N, τ).

  • population::Integer: known number at risk N (N ≥ K).
  • population::NGrid: unknown N, summed out over the grid's prior support with marginal_N_loglik (the grid must have been built for this K).

τ may be a ForwardDiff Dual.

source
DiscreteDynamicSurvivalAnalysis.infection_time_loglik — Function
infection_time_loglik(counts, f)

Infection-time term ℓ_I: log Multinomial(counts; sum(counts), f), the probability of the observed histogram of infection steps given the normalised infection-time distribution f of the map (same length as counts). Zero when there are no counts.

source
DiscreteDynamicSurvivalAnalysis.recovery_loglik — Function
recovery_loglik(d, intervals, censored = falses(length(intervals)))

Recovery term ℓ_R: Σ log P(W = δᵢ) over the observed intervals plus Σ log P(W > δᵢ) over the right-censored ones, for the infectious-period distribution d (a DPH or any discrete distribution with logpdf/logccdf).

source
DiscreteDynamicSurvivalAnalysis.removal_only_loglik — Function
removal_only_loglik(d, f, removal_steps)

Likelihood of cases whose infection time is unknown but whose removal step T is known: for each, log Σ_{u=1}^{min(T-1, nsteps)} f[u] P(W = T - u), summing over the possible infection steps u with the infection-time distribution f and the infectious-period distribution d. A removal at step 1 has likelihood zero (-Inf).

Simulation

DiscreteDynamicSurvivalAnalysis.simulate_linelist — Function
simulate_linelist(rng, dph::DPH, β, ρ, N, nsteps; M = 1, Δt = 1.0) -> NamedTuple

Draw a synthetic line list from the DDSA working model. The GLCT forward map with infectious period dph, transmission rate β (per unit time) and initially infected fraction ρ gives the attack fraction τ and the infection-time distribution f over nsteps steps of length Δt; then

  1. the final size K ~ Binomial(N, τ),
  2. the infection-step histogram ~ Multinomial(K, f),
  3. M + K recovery intervals drawn independently from dph (the M initial infectives and the K new cases), by inversion with one uniform each.

Returns (data = LineList, τ, f).

DiscreteDynamicSurvivalAnalysis.simulate_chain_binomial — Function
simulate_chain_binomial(rng, dph::DPH, β, N; M = 1, Δt = 1.0, max_steps = 5000) -> NamedTuple

Simulate a stochastic chain-binomial SIR outbreak, for checking DDSA on data that do not come from its own (mean-field) working model. N susceptibles and M initial infectives (ρ = M / (N + M) in the map's convention): on each step k, the number of new infections is Binomial(S, 1 − exp(−β I Δt / (N + M))) (frequency-dependent transmission, as the map), and each new infective's infectious period W is drawn from dph at infection: infected on step k, it is infectious on steps k + 1, …, k + W and its recorded interval is W. The initial infectives are infected at step 0. The outbreak runs until no infectives remain (or max_steps).

Returns (data, infection_steps, removal_steps, seed_intervals), where data is a complete LineList up to the last removal (no censoring; its recovery intervals include the initial infectives and its final size counts the new infections), so the matching final-size term is Binomial(N, τ) over the N initially susceptible.

PhaseTypeDistributions

DiscreteDynamicSurvivalAnalysis.PhaseTypeDistributions — Module
PhaseTypeDistributions

Continuous and discrete phase-type distributions.

  • Continuous phase-type (PhaseType): time to absorption of a continuous-time Markov chain with initial distribution α and transient generator A; density f(t) = α' exp(A t) q.
  • Discrete phase-type (DPH): number of steps to absorption of a discrete-time Markov chain with initial distribution α and sub-stochastic transition matrix S; P(W = n) = α' S^(n-1) s for n ≥ 1, with absorption vector s = 1 - S 1.
  • Smooth negative binomial (SmoothDPH): mixture of the ⌊r⌋- and ⌊r⌋+1-stage negative binomial DPHs, so that the number of stages r can be real-valued.

All types are Distributions.Distributions: pdf, logpdf, cdf, mean, var, rand, … are methods of the Distributions/Statistics/Random functions (re-exported here), so they work with or without this module's prefix and compose with Turing.jl. Element types are generic, so ForwardDiff Dual numbers pass through the constructors and the discrete-PH methods.

Loading

using DiscreteDynamicSurvivalAnalysis                          # re-exports everything below
using DiscreteDynamicSurvivalAnalysis.PhaseTypeDistributions   # this submodule only

Example

d = dph_negative_binomial(4, 0.6)   # 4 stages, per-step progression probability 0.6
pdf(d, 7), mean(d)                  # P(W = 7), r/p = 6.67 steps
erl = ph_erlang(3, 1.5)             # continuous Erlang, 3 phases, rate 1.5
cdf(erl, 2.0)

DiscreteDynamicSurvivalAnalysis.PhaseTypeDistributions.dph_prepend_deterministic_delay — Function
dph_prepend_deterministic_delay(dph::DPH, c::Integer)

Return a new DPH that prepends c ≥ 0 deterministic transient states in front of the chain described by dph. Each prepended state advances to the next with probability 1 on the next step (no absorption from those states); after c steps the process enters the original states according to dph.α and then evolves with dph.S. The time to absorption increases by exactly c steps: E[W_new] = c + E[W_core]. c = 0 returns dph unchanged.

Use this when a dwell time has a known minimum (e.g. fixed clinical offsets) while the stochastic tail remains phase-type.

Example

core    = dph_negative_binomial(3, 0.25)         # minimum 3
delayed = dph_prepend_deterministic_delay(core, 2) # minimum 5

DiscreteDynamicSurvivalAnalysis.PhaseTypeDistributions.dph_coxian — Function
dph_coxian(w, p; first_exit = 1)

Coxian DPH whose stages share the per-step progression probability p ∈ (0, 1]. The chain has k = first_exit + length(w) - 1 stages, passed in order at most one per step. After stage j = first_exit, …, k an individual leaves with probability w[j - first_exit + 1] (the weights are non-negative and sum to 1) and otherwise moves on to stage j + 1. The number of steps to absorption is the mixture

P(W = n) = Σⱼ w_j C(n-1, j-1) p^j (1-p)^(n-j),

with mean Σⱼ w_j j / p. Its support starts at the first stage with positive weight, however many stages the chain has. All the weight on the last stage gives dph_negative_binomial(k, p).

As a DPH, stage j is kept with probability 1 - p. When it is left, the individual is removed with probability e_j = w_j / (w_j + w_{j+1} + …) and moves to stage j + 1 otherwise. An exit with p e_j < 1e-12 is dropped (its weight moves to the next exit), so that the rows of S sum to at most 1 in floating point. logpdf recognises the structure and uses the closed form of the mixture. Element types are generic, so w and p may be ForwardDiff Duals.

Example

d = dph_coxian([0.1, 0.2, 0.7], 0.6; first_exit = 2)   # 4 stages; leave after stage 2, 3 or 4
pdf(d, 2), mean(d)                                      # 0.036, 6.0

DiscreteDynamicSurvivalAnalysis.PhaseTypeDistributions.dph_from_rates — Function
dph_from_rates(α, A, Δt=1.0)

Discretise a continuous-time phase-type chain (initial distribution α, normalised; generator A) on steps of length Δt, allowing at most one jump per step: state i is kept with probability exp(-q_i Δt) (q_i = -A[i,i]) and left for state j with probability (A[i,j] / q_i) (1 - exp(-q_i Δt)). DiscreteDynamicSurvivalAnalysis.PhaseTypeDistributions.discrete_hazard — Function
discrete_hazard(d::DPH, K::Integer; truncation = :absorb) -> Vector

Removal probability per age class, h[1:K], of a Boxcar (infection-age) structure with K classes whose dwell time follows d. The last class removes everyone (h[K] = 1) and every entry is clamped to [0, 1]. Two truncations are available:

  • truncation = :absorb: the exact hazard h[k] = P(W = k) / P(W ≥ k) for k < K, so the dwell time in the map is min(W, K). Computed by iterating the state vector; where P(W ≥ k) falls below 1e-15 the hazard is set to 0.01 (no mass is left at those ages).
  • truncation = :condition: the hazard of W conditioned on W ≤ K, h[k] = P(W = k) / P(k ≤ W ≤ K). Geometric, negative binomial and delayed negative binomial DPHs use the backward recursion h[k] = h[k+1] / (h[k+1] + P(W = k+1) / P(W = k)) from h[K] = 1. The PMF ratio is rational in p, so no logs or exponentials are needed, and values and ForwardDiff derivatives stay finite at every age. Other DPHs accumulate the truncated survival on the log scale from age K down, from log(pmf); ages where it underflows get h = 0.

The two coincide when P(W > K) is negligible.

negbin_total_logpdf(k, r, p)

IntegerParameters

DiscreteDynamicSurvivalAnalysis.IntegerParameters — Module
IntegerParameters

Exact summation of integer-valued parameters out of a likelihood, so the real-valued parameters can be sampled with NUTS alone (no Gibbs/MH blocks).

  • Summing over N (NGrid, marginal_N_loglik): a population size N that enters the likelihood only through the Binomial final-size term K ~ Binomial(N, τ). log C(N, K) is precomputed, so supports of thousands of values cost one vectorised pass per evaluation.
  • Summing over r (marginal_r_loglik): any finite set of values (a phase count r, or pairs such as (r, N₂)) whose likelihood must be recomputed for each value, e.g. because it changes the forward map or the infectious-period distribution. This costs one likelihood evaluation per value, so keep the support small (tens of values).

After sampling, posterior draws of the summed-out parameters are recovered with sample_N and sample_index, using the exact conditional posterior for each MCMC draw.

Which helper to use:

  • N enters only K ~ Binomial(N, τ): NGrid + marginal_N_loglik.
  • The parameter changes the forward map or the recovery distribution (e.g. r, or N when ρ = 1/N): marginal_r_loglik over its support.
  • Several parameters each change the map: sum over their joint grid (Iterators.product), at a cost equal to the product of the support sizes. Parameters that enter separate Binomial terms each get one NGrid, added together.

marginal_N_loglik and marginal_r_loglik accept ForwardDiff Dual arguments (τ and log-likelihoods); N_posterior_weights, posterior_weights, sample_N and sample_index work in Float64 and are meant for use after sampling.

DiscreteDynamicSurvivalAnalysis.IntegerParameters.marginal_r_loglik — Function
marginal_r_loglik(loglik_r, support; logprior = nothing, threaded = false)

Sum a discrete parameter out of the likelihood:

log Σ_{r ∈ support} π(r) exp(loglik_r(r))

loglik_r(r) returns the log-likelihood for value r given the current real-valued parameters; return -Inf for infeasible values (for example r > minimum(delta) for a NegBin DPH) so they cost nothing. support can be any finite collection, including tuples for a joint grid such as Iterators.product(1:4, 68:77).

logprior is an optional vector of log prior weights in the same order as support; the default is uniform over support.

threaded = true evaluates the values as parallel tasks (when Julia runs with more than one thread). This helps when each loglik_r call is expensive, for example a forward-map run per value over a large grid. loglik_r must then be safe to call concurrently (no shared mutable state). The result is identical to the serial one.

Returns (logmarg, lps), where lps holds the per-value log-likelihoods. Return lps from the Turing model so the posterior of r can be recovered afterwards with posterior_weights or sample_index:

logmarg, lps = marginal_r_loglik(r -> ll_given_r(r, β, ρ, p), 1:r_max)
Turing.@addlogprob! logmarg
return lps
